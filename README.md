# Learning PowerShell

This is just me learning PowerShell from scratch.

I followed the **JackedProgrammer** PowerShell series on YouTube, and as I went through each lesson I wrote the scripts myself and added my own study comments. So if you open any file, you'll find the code alongside my notes explaining what's going on, like I'm talking you through it.

## What's inside?

Each folder is a lesson, in the order I went through them:

| # | Lesson | What it covers |
|---|--------|----------------|
| 1 | Introduction | Installing PowerShell 7, setting up VS Code, and running a few commands |
| 2 | Variables | Variables, data types, Arrays vs ArrayLists, HashTables & Custom Objects |
| 3 | Pipeline | Passing the output of one command as an input to another |
| 4 | If-Else | Comparison operators, if/elseif/else, and switch |
| 5 | ForEach | ForEach, ForEach-Object, for, while, do-while & do-until |
| 6 | Error Handling | Try/Catch/Finally, terminating vs non-terminating errors |
| 7 | Modules | Finding, importing and installing modules |
| 8 | Methods | Writing your own functions, parameters, pipeline support, Verbose & Debug |
| 9 | Modules-P2 | Creating your own module, its Manifest, and a Get-Help manual |
| 10 | Remoting | Script blocks, Invoke-Command, and persistent sessions |
| 11 | Pester | Writing and running tests with Pester |
| 12 | Files | Reading and exporting CSV & JSON files, plus JSON from an API |

## How to use it?

Simple, open the folder in VS Code with the PowerShell extension, pick a lesson, and run the lines one by one (F8 runs the selected line).

A couple of things to keep in mind:
- Some file paths point to the machines I was using at the time, so you'll need to change them to match yours.
- The Remoting and Pester lessons connect to a remote machine, so you'll need one of your own to try them.
